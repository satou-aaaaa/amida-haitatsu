# あみだ配達

あみだくじに横線を足して、上の手紙をそれぞれ同じ字の家へ届ける。いちばん少ない本数を目指す、だれでも同じ1日3問のパズル。

- 遊ぶ: <https://satou-aaaaa.github.io/amida-haitatsu/>
- 手紙は縦の道を下へ進み、横線があれば必ず渡ります。縦の道のあいだを押すと横線を引け、もう一度押すと消せます。横線はとなり合わせに引けません。はじめからある横線（墨色）は消せず、工事中（だいだい）の所には引けません。
- いちばん少ない本数は、問題を作るときに全部の引き方を数えて出しています（問題の上に出ます）。その本数で届けてヒントも使わなければ★3つ。
- 今日の3問（4本・5本・6本の道）はだれでも同じで1日1回。上級（7本の道を2つ・ヒントなし）、練習、道の数ごとの記録が残る配達帳、実績があります。時間制限はありません。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（道は入りません）。

## 開発

```bash
bash scripts/setup.sh   # 最初に一度
node qa/run.mjs         # 検査（CI と同じ）
node tools/make-icons.cjs && node tools/make-og.cjs   # アイコンと SNS 用の絵を作り直すとき
```
